# 반복단타 스캐너 통합 설계 보고서

**작성일:** 2026-08-17 (KST)  
**대상:** `ymym` Streamlit 스캐너  
**목적:** 한국 정규장과 미국 프리·정규·애프터에서 0.5~5.0% 반복폭을 보이는 고유동성 종목을 찾고, 사용자에게 **진입 기준가·1차 목표·2차 목표·무효화 가격·판정 근거**를 일관된 화면으로 제시한다.

> 이 문서는 연구·분석 및 소프트웨어 설계 목적입니다. 신호, 목표가, 승률 또는 수익을 보장하지 않으며, 실제 주문은 사용자가 직접 판단하고 실행해야 합니다.

## 1. 결론과 설계 범위

현재 스캐너는 단일 `진입 고려` 판정과 1개 목표가·손절가 중심이어서, 사용자가 “왜 지금 대기인지”, “박스 하단에서 어느 가격을 기준으로 진입해야 하는지”, “1차 청산 뒤 얼마나 더 보아야 하는지”를 읽기 어렵다. 또한 기존 5분 박스 폭 상한이 3.0%이고, 미국 분봉 요청이 최근 120개에 한정되어 있어 **5시간 반복단타**를 검증하기에 데이터가 부족하다.

통합 버전은 하나의 전략으로 모든 상황을 처리하지 않는다. 장세를 **상승 추세 눌림 반복단타**와 **박스 하단 평균회귀 반복단타**로 나눈 뒤, 공통적으로 세션·호가 스프레드·거래량·거래대금·완료된 캔들·가격 구조·비용 반영 손익비를 통과해야만 진입 신호를 낸다. 두 전략의 공통 부분은 데이터 검증과 위험 통제이며, 진입과 청산의 구조는 분리한다.

| 구분 | 상승 추세 눌림 반복단타 | 박스 하단 평균회귀 반복단타 |
|---|---|---|
| 시장 상태 | 15·60분 추세가 상승이고 가격이 VWAP 상단에 유지 | 5분봉에서 0.5~5.0% 범위, 상·하단 각 2회 이상 접촉 |
| 진입 기준 | EMA9 또는 VWAP 부근의 눌림 뒤, 완료 1분봉 회복 | 박스 하단 0~40% 구간에서 지지 확인 |
| 1차 목표 | 가장 가까운 확인된 1분봉 저항 또는 박스 중단 | 박스 중단값 |
| 2차 목표 | 다음 확인 저항 또는 상단 연장 구간 | 박스 상단값 |
| 무효화 | 지지 하단 아래의 ATR 버퍼를 2개 완료 1분봉 종가로 이탈 | 박스 하단 아래의 ATR 버퍼를 2개 완료 1분봉 종가로 이탈 |
| 진입 금지 | 저항 돌파 후 재진입 실패, 거래량 부재, 스프레드 과다 | 박스 이탈, 범위 과대·과소, 반대편 접촉 부족, 거래량 급감 |

## 2. 실시간 데이터 구조와 5시간 요구사항

“최소 5시간 반복”은 한 번의 현재가 조회만으로 판정할 수 없다. 1분봉 300개 이상을 확보하고, 같은 날짜·같은 세션의 VWAP·ATR·거래량 기준을 유지해야 한다. 현재 KIS 클라이언트는 미국 1분봉을 최근 120개로 요청하므로, 스캐너는 데이터가 300개 미만이면 **‘5시간 검증 준비 중’**으로 표시하고 5시간 반복 검증 완료라는 표현을 사용하지 않아야 한다.

| 운영 방식 | 사용자 경험 | 장점 | 한계 및 비용 |
|---|---|---|---|
| 화면을 켠 뒤 수동 분석·저빈도 갱신 | 현재 Streamlit 앱 방식 | 즉시 사용 가능, KIS 호출량 제어가 쉬움 | 앱을 열기 전의 5시간 분봉은 누적되지 않음 |
| 별도 수집 프로세스가 장중 1분봉을 계속 누적 | 같은 화면에서 5시간 이상 종목 상태 제공 | 세션 VWAP·반복 횟수·가짜신호 재진입 검증 가능 | 항상 실행되는 데이터 수집 환경과 KIS 호출 한도 설계가 필요 |

기본 적용은 첫 번째 방식으로 하되, 코드와 화면은 두 번째 방식으로 확장할 수 있도록 `데이터 준비도`를 분리한다. 지속 수집을 켜는 경우에는 사용자가 별도의 항상 실행 환경과 KIS의 실제 호출·데이터 범위 정책을 확인해야 한다. Streamlit 화면만으로 시장 전체를 지속 감시하는 방식은 호출 제한, 프로세스 재시작, 데이터 누락 때문에 신뢰할 수 있는 5시간 감시 구조가 아니다.

## 3. 수학적 신호 정의

### 3.1 공통 계산

각 계산은 **진행 중인 마지막 1분봉을 제외한 완료 1분봉**만 사용한다. 다음 표의 정의는 구현과 보고서에서 동일하게 유지한다.

| 지표 | 정의 | 목적 |
|---|---|---|
| 세션 VWAP | \(\sum TypicalPrice_t \times Volume_t / \sum Volume_t\) | 세션 평균 체결 가격 대비 수급 방향 확인 |
| ATR(14) | True Range의 14기간 지수평활 평균 | 종목별 변동성에 맞춘 무효화 버퍼와 목표 거리 계산 |
| 상대거래량 | 최근 1분 거래량 ÷ 직전 20분 평균 거래량 | 돌파·반등이 거래량 없이 발생하는 가짜 신호 차단 |
| 거래대금 상대강도 | 최근 5분 \(Close \times Volume\) ÷ 직전 20분 5분 환산 중앙값 | 단순 체결 수가 아니라 실제 금액 유입 확인 |
| 스프레드 | \((Ask-Bid)/((Ask+Bid)/2) \times 100\) | 진입 즉시 발생하는 마찰비용과 유동성 부족 차단 |
| 박스 폭 | \((BoxHigh/BoxLow-1) \times 100\) | 0.5~5.0% 반복폭 조건 검증 |
| 순손익비 | \((Target_1-Entry-Cost)/(Entry-Invalidation+Cost)\) | 비용을 포함한 첫 목표 기준 보상·위험 비교 |

VWAP는 가격과 거래량을 결합한 장중 평균 가격이지만, 단독으로 예측 지표가 아니다. 따라서 스캐너는 VWAP, 다중 시간대 구조, 거래량·거래대금, 스프레드, 완료 캔들을 결합해 사용한다.

### 3.2 상승 추세 눌림 반복단타

상승 모드는 15분과 60분에서 `EMA9 ≥ EMA20` 및 양의 회귀 기울기가 동시에 확인되고, 현재가가 세션 VWAP 상단에 있을 때만 후보가 된다. 진입은 가격이 EMA9·VWAP 부근으로 눌린 후 1분봉 종가가 다시 해당 기준 위에서 마감할 때 고려한다. 단순 상승 추격을 막기 위해 현재가가 1차 저항에 너무 가까워 순손익비가 기준보다 낮으면 신호를 차단한다.

1차 목표는 가장 가까운 완료 1분봉 스윙 저항, 2차 목표는 그 다음 스윙 저항 또는 박스 상단이다. 무효화 가격은 지지 저점에서 `max(0.25 × ATR, 시장별 최소 틱 완충)`을 뺀 값으로 계산한다. 단, 순간적인 꼬리 하락만으로 손절 판단을 고정하지 않고, 해당 무효화 가격 아래에서 **2개 연속 완료 1분봉 종가**가 확인될 때 ‘구조 무효화’로 표시한다.

### 3.3 박스 하단 평균회귀 반복단타

박스 모드는 완료된 5분봉 12개 이상에서 20% 저점 분위수와 80% 고점 분위수로 후보 범위를 만들고, 범위 폭이 0.5~5.0%이며 상·하단을 각각 최소 2회 접촉했을 때만 인정한다. 진입 기준가는 박스 하단에서 폭의 0~40% 구간이며, 하단을 이탈한 뒤 회복한 경우에는 다음 완료 1분봉이 하단 위에서 마감해야 한다.

1차 목표는 박스 중단값, 2차 목표는 박스 상단값이다. 이는 ‘한 번에 전량 청산’이 아니라 사용자가 1차 목표에서 일부 수익을 확인하고 나머지를 2차 목표 또는 구조 변화에 따라 관리할 수 있도록 하는 참고 구조다. 박스 폭이 5.0%를 넘으면 한 전략 안에서 다루기에는 변동성 위험이 크므로 대기 처리한다.

## 4. 가짜 신호와 가짜 손절 필터

가짜 신호를 완전히 제거할 수는 없지만, 검증 가능한 조건으로 차단 빈도를 높일 수 있다. 모든 필터는 완료된 캔들 기준으로 계산하며, 미확정 장중 고가·저가를 미래 정보처럼 사용하지 않는다.

| 필터 | 차단 조건 | 화면 문구 |
|---|---|---|
| 저항 돌파 실패 | 고가가 저항을 넘었지만 종가가 저항 아래로 복귀 | `돌파 실패: 재진입 대기` |
| 약한 돌파 | 저항 상향 종가이나 상대거래량 또는 거래대금 상대강도가 기준 미만 | `거래량 확인 부족` |
| 윗꼬리 거부 | 윗꼬리가 몸통의 1.5배 이상이고 종가가 캔들 하단에 위치 | `매도 압력 경고` |
| 가짜 하향 이탈 | 저가가 지지 아래이나 종가가 지지 위로 회복 | `지지 이탈 후 회복: 즉시 손절 대신 완료봉 확인` |
| 구조 무효화 | 무효화 가격 아래에서 2개 완료 1분봉 종가가 연속 확인 | `구조 무효화: 신규 진입 중단` |
| 유동성 부족 | 스프레드가 세션 한도 초과 또는 호가 누락 | `체결 비용 과다: 대기` |

이 규칙은 손실을 없애지 않는다. 특히 미국 프리·애프터는 정규장보다 유동성이 낮고 변동성이 크며 스프레드가 넓을 수 있으므로, 정규장보다 높은 거래량·거래대금 요건과 더 낮은 허용 스프레드가 필요하다.[1] [2]

## 5. 80% 승률 목표의 검증 규칙

80%는 설계 목표가 아니라 **전략별·세션별·시장별 검증 결과가 충족해야 하는 운영 기준**으로 다룬다. 수익 보장이나 진입 신호의 사전 확률로 표시하지 않는다. 표본이 적은 80%는 신뢰할 수 없으므로, 전략·세션별로 최소 50개 이상의 독립 신호를 확보하고, 동일한 왕복비용·스프레드·지연 가정으로 순손익을 계산해야 한다.

| 검증 항목 | 통과 기준 | 비고 |
|---|---|---|
| 표본 수 | 전략·세션별 50건 이상 | 한국 정규장, 미국 프리·정규·애프터를 혼합하지 않음 |
| 승률 | 순비용 반영 수익 거래 비율 80% 이상 | 단, 목표 도달과 손절 도달이 동일 1분봉이면 보수적으로 손실 처리 |
| 수익요인 | 총이익 ÷ 총손실 절댓값 > 1.2 | 승률만 높은 작은 수익·큰 손실 구조 차단 |
| 최대 연속 손실 | 사전에 정한 한도 이내 | 한도 초과 시 해당 모드 자동 경고 |
| 표본 분리 | 날짜 순서 기준 학습·평가 분리 | 미래 데이터 누수 방지 |

현재 프로젝트에는 이 기준을 충족하는 실제 장중 표본이 없다. 따라서 앱은 `검증표본 부족`, `관찰`, `진입 고려`를 구분하되, 80% 승률을 달성했다고 표시하지 않는다. 실전 사용 전에는 해당 시장·세션별 원본 1분봉으로 과거검증과 모의기록을 축적해야 한다.

## 6. 화면 정보 구조

참조 화면처럼 상단에서 결론을 읽고, 하단에서 근거와 차트를 확인하도록 설계한다. 사용자가 원하지 않는 복잡한 지표명은 기본적으로 접고, ‘왜 대기인지’와 ‘가격 기준’은 평이한 한국어로 전면 표시한다.

| 영역 | 표시 내용 | 사용자 질문에 대한 답 |
|---|---|---|
| 후보 상태 배너 | `진입 고려` / `대기` / `구조 무효화`와 전략명 | 지금 매매를 고려해도 되는가? |
| 핵심 가격 카드 | 현재가, 진입 기준가, 1차 목표, 2차 목표, 손절·지지 | 어디를 기준으로 나눠서 대응하는가? |
| 근거 요약 | 추세, 박스 폭, 거래량, 거래대금, 스프레드, 순손익비, 가짜신호 경고 | 왜 이 가격이 계산됐는가? |
| 데이터 준비도 | 완료 1분봉 수, 5시간 검증 상태, 세션 | 이 결과를 얼마나 믿을 수 있는가? |
| 차트 | 현재가·진입·1차·2차·무효화·박스 상하단 | 가격 구조가 실제로 어떻게 생겼는가? |
| 상세 지표 | VWAP·EMA·ATR·상대거래량 등 | 더 깊게 확인하려면 무엇을 보는가? |

## 7. 구현 순서

첫 구현은 현재 KIS REST 데이터와 Streamlit 환경 안에서 동작하는 수동 분석 도구로 한정한다. 코드에서는 0.5~5.0% 박스 탐지, 2차 목표가, ATR 기반 구조 무효화, 가짜 돌파·가짜 이탈 경고, 거래대금 상대강도, 전략별 점수와 화면 설명을 추가한다. 종목 전체를 실시간으로 끝없이 탐색하는 기능은 별도 장중 수집·저장·호출량 관리 체계가 검증된 뒤 확장한다.
