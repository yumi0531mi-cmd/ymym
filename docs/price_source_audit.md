## 실제 대조 기록

2026-08-18 12:54 KST에 KIS 국내 현재가 API로 주성엔지니어링 `036930`을 조회한 결과는 **183,500원**이었다. 같은 점검에서 Yahoo KOSDAQ 1분봉의 마지막 값은 **181,500원**, 시각은 **12:35 KST**였다. 따라서 Yahoo 시세를 현재가로 사용할 수 없으며, 현재가 기준으로 표시한 기존 경로는 제거 대상이다.

KIS 단일 원천 전환 후 13:02 KST에 다시 점검한 결과, 주성엔지니어링 KIS 기준 현재가는 183,050원이었고 국내 KIS 1분봉 첫 페이지와 직전 페이지를 결합해 **59개**를 확보했다. 같은 점검에서 미국 AAPL은 KIS 해외 기준 현재가 305.59달러와 **120개**의 KIS 1분봉을 반환했다. 따라서 국내 정규장과 미국 세션의 카드 구조 계산에 필요한 완료봉은 모두 KIS 경로에서 확보할 수 있다.

KIS 단일 원천 커밋 직후 Streamlit Cloud 브라우저 화면은 재배포·세션 재시작 과정에서 이전 Yahoo 카드 내용이 잠시 남아 있는 전환 상태를 보였다. 최종 배포가 완료된 뒤 새 세션에서 `KIS REST 기준` 문구와 KIS 수신 시각을 다시 확인해야 한다.

최종 재배포 화면에서는 `0167A0 · SOL AI반도체TOP2플러스` 카드에 `KIS REST 기준 · KIS 시각 13:06:41`과 18,070원이 표시됐고, Yahoo 문구는 사라졌다. 이후 13:07:27 KST에 같은 종목을 KIS API로 직접 다시 조회한 값은 18,080원이었다. 두 값의 차이는 서로 다른 KIS 수신 시각 사이의 장중 변동이며, 카드와 직접 조회 모두 KIS 원천임을 확인했다.

주성엔지니어링 카드도 `KIS REST 기준 · KIS 시각 13:11:42`와 183,500원으로 표시된 뒤, 13:12:23 KST의 직접 KIS 조회에서 183,300원이 반환됐다. 이 역시 서로 다른 KIS 수신 시각 사이의 변동이며, 이전의 Yahoo 보조 가격과 달리 카드와 대조 조회가 같은 KIS 원천을 사용함을 확인했다.

다음 카드 갱신에서는 `KIS 시각 13:12:44`와 183,300원이 표시돼, 앞선 직접 KIS 조회값과 일치했다. 이로써 카드 가격이 KIS REST 캐시 주기마다 같은 KIS 기준가로 갱신되는 것을 확인했다.

## 수정 원칙

국내는 KIS 국내 현재가·KIS 국내 완료 1분봉, 미국은 KIS 해외 현재가·KIS 해외 완료 1분봉만 카드의 기준 가격으로 사용한다. KIS WebSocket 체결이 연결된 경우에만 1초 수신 체결가를 표시한다. WebSocket이 연결되지 않은 환경에서는 KIS REST 기준 현재가를 **30초 캐시 주기**로 갱신하고, 마지막 KIS 수신 시각을 같이 표시한다. 최대 5개 카드의 KIS REST 갱신은 분당 10건이며, 초기 후보·호가·분봉 조회까지 포함해도 분당 30건 제한 안에 머물도록 구성한다.

완료 1분봉이 충분하지 않으면 매수가·목표가·손절가를 임의로 보완하지 않고 `완료 분봉 수집 중`으로 표시한다. 전체 경로 검증은 KIS 기준 가격과 KIS 완료 1분봉으로만 기록한다.
