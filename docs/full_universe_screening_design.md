# 전종목 후보 선별 설계

## 의미와 범위

여기서 전종목 스크리닝은 국내 KRX와 미국 NASDAQ·NYSE·AMEX의 각 시장에서 **순위 API가 반환하는 시장 전체 후보군**을 1차로 선별한다는 뜻이다. 수천 종목의 1분봉·호가를 동시에 전수 조회하는 방식은 KIS 호출 제한과 응답 지연 때문에 사용하지 않는다.

## 단계형 처리

| 단계 | 국내 | 미국 | KIS 예상 호출 |
|---|---|---|---:|
| 1차 시장 후보 | 거래대금/거래량 순위 + 상승률 순위 | NASDAQ·NYSE·AMEX별 거래대금 순위 + 상승률 순위 | 국내 2건 / 미국 6건 |
| 후보 통합 | 코드 중복 제거, 최소 가격·거래량·등락률 필터, 출처별 점수 부여 | 같은 방식 | 0건 |
| 정밀 분석 | 사용자가 고른 종목만 현재가·1호가·1분봉 확인 | 같은 방식 | 선택 종목당 최대 3건 |

전종목 빠른검색은 순위 API 1페이지에서 제공하는 후보만 사용한다. 페이지를 계속 넘겨 전체 순위표를 누적하지 않으므로 호출량이 정해져 있다. 현재 설정한 1분 30건 예산 안에서 국내는 순위 조회 2건 뒤 선택 종목 분석 3건, 미국은 순위 조회 6건 뒤 선택 종목 분석 3건을 사용할 수 있다.

## 후보 점수

순위 응답에서 종목 코드·이름·현재가·등락률·거래량·거래대금이 확인되면 다음처럼 **후보 우선순위**만 계산한다. 이는 매수 신호나 수익 예측이 아니다.

| 조건 | 후보 점수 |
|---|---:|
| 거래대금/거래량 순위에 포함 | 45점 |
| 상승률 순위에 포함 | 35점 |
| 두 순위 모두 포함 | 추가 20점 |

동일 종목은 두 순위의 점수를 합산해 상단으로 올린다. 상위 후보는 직접 선택해 기존 `선택 종목 분석`을 실행해야만 완료 1분봉 진입·손절과 완료 5분봉 목표가가 계산된다.

## 외부 보조 데이터

MIT 라이선스가 명시된 dd3ok의 네이버·토스 기반 코드는 종목 검색·시장 랭킹·뉴스/테마·공시 화면의 데이터 모델을 참고할 수 있다. 그러나 이들은 비공식 공개 웹 인터페이스로서 고빈도·대량 수집을 허용하지 않는 안전 경계를 명시한다. 따라서 본 앱의 반복단타 기준 가격·호가·분봉에는 사용하지 않고, 저빈도 보조 컨텍스트에 한정한다. Yahoo Finance 관련 저장소는 라이선스가 명시되지 않아 코드를 재사용하지 않는다.
