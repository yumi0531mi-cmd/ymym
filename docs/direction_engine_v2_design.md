# 단계형 시간대 방향 엔진 설계

## 목적

이 설계는 상승·반복단타 혼합 스캐너에서 **5·15·30분의 방향과 예상 이동범위**를 같은 속도로 연장하지 않도록 한다. 각 시간대는 차트 상태와 데이터 역할에 맞는 별도 방향 엔진을 사용한다. 여기에서 산출하는 점수는 확률로 표시하지 않으며, 실제 KIS 경로 결과가 충분히 쌓인 뒤에만 보정된 확률로 전환한다.

## 단계 흐름

```text
데이터 품질
→ TREND / RANGE / BREAKOUT 상태
→ confirmed Swing · 지지 · 저항 · 박스 구조
→ 시간대별 Direction Engine (5·15·30분)
→ 예상 이동범위
→ 1차·2차 목표 도달 조건
→ SHAKEOUT / REAL_BREAKDOWN 무효화
→ Persistence / Pattern Fatigue
→ 실제 5·10·15·30분 경로 저장
→ 지표 추가 기여도 재검증 · Calibration
```

## 데이터 품질 관문

완료된 1분봉 30개 이상, 양수 가격·거래량, 정상 고가/저가 관계, 거래 가능 세션, 호가 스프레드, 최근 현재가 원천을 확인한다. RSI·ADX·ATR 등 길이가 필요한 지표는 충분한 완료봉이 없으면 해당 지표를 방향 점수에 넣지 않는다. 진행 중인 분봉은 구조·방향 판단에서 제외한다.

## 상태 분리

| 상태 | 구조 기준 | 방향 해석 |
|---|---|---|
| `TREND` | 고점·저점 상승 또는 하락, VWAP/EMA 정렬, 추세 지속성 | VWAP·EMA·Swing·거래량의 지속성을 우선한다. |
| `RANGE` | 반복 박스, 낮은 방향 효율, 지지·저항 반복 접촉 | 박스 하단/상단과 Stochastic·RSI의 재진입 타이밍을 우선한다. |
| `BREAKOUT` | 완료봉 돌파, 거래량·거래대금 강화, 돌파 가격 위 재지지 | 체결·호가·거래량과 재지지를 우선한다. 확인 전에는 다음 저항으로 목표를 확장하지 않는다. |
| `TRANSITION` | 상기 구조가 명확하지 않음 | 방향 신뢰도를 낮추고 관망 또는 짧은 범위만 허용한다. |

## 시간대별 엔진

| 시간대 | 가장 큰 역할 | 보조 역할 | 장기 연장 방지 |
|---|---|---|---|
| 5분 | 체결·호가·단기 거래량, 확인 Swing | VWAP/EMA, Stochastic 타이밍 | 위험상태와 스프레드가 나쁘면 즉시 `FLAT` 또는 `DOWN` |
| 15분 | 완료 5분봉 구조, 지지·저항 | 추세 지속성과 변동성 | 5분 반등을 그대로 연장하지 않음 |
| 30분 | 다음 스윙 저항, 박스 상단, Persistence·Pattern Fatigue | 큰 추세와 변동성 | 구조 저항과 총 5% 단타 상한을 넘지 않음 |

## 지표 역할과 중복 관리

| 역할 | 후보 지표 | 유지 기준 |
|---|---|---|
| 구조 | Swing, HH/HL·LH/LL, 지지·저항, 반복박스, 돌파·실패 돌파 | 모든 상태에서 본체 입력 |
| 추세 | VWAP, EMA9/20/60, ADX, +DI/-DI, 회귀 기울기 | 구조 대비 시간대별 추가 설명력이 있을 때 유지 |
| 모멘텀 | Stochastic, RSI, MACD 히스토그램, ROC | Stochastic은 재진입 타이밍, RSI는 과열/다이버전스, MACD는 EMA와 중복 검사 |
| 거래량·자금흐름 | RVOL, 거래대금 상대강도, OBV, CMF, MFI | 체결·호가 및 구조를 보강하는 경우에만 유지 |
| 변동성 | ATR/NATR, Bollinger 폭·%B, 표준편차 | 방향이 아니라 시간대별 예상 이동범위·손절 완충에 사용 |
| 캔들 | 장악형, 망치형, 긴 윗꼬리·아랫꼬리, Inside bar | 독립 방향 점수가 아닌 구조 확인용 |

서로 비슷한 지표를 자동으로 하나만 삭제하지 않는다. 같은 상태·시간대에서 실제 5·10·15·30분 결과를 비교해 **기존 요인 대비 추가 예측력이 없는 경우에만** 제거하거나 가중치를 낮춘다. TA-Lib는 ADX·RSI·MACD·Stochastic·ATR 등 다양한 표준 기술지표를 제공하지만, 지표 수가 곧 독립 정보 수를 뜻하지는 않는다. [TA-Lib][1] [Momentum functions][2] [Volatility functions][3]

## 위험 무효화와 검증

`SHAKEOUT`은 지지 이탈 뒤 완료봉 회복으로, 즉시 하방 확정 대신 짧은 회복 관찰로 처리한다. `REAL_BREAKDOWN`은 지지 아래 연속 완료봉과 매도 거래량 증가가 함께 나타난 경우로, 해당 시간대 상방 방향을 무효화한다. Pattern Fatigue는 최근 Swing 폭 축소·주기 지연·지속성 약화를 점수에 반영하며, 15·30분 엔진에서 더 크게 감점한다.

모든 표본은 원천과 함께 5·15·30분 실제 가격을 저장한다. 통과 여부는 각 시간대에서 **방향과 예측 범위가 모두 일치**할 때만 인정한다. 지표·상태·시간대 조합의 가중치는 충분한 실제 표본이 누적된 뒤에만 바꾼다.
