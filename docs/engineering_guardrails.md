# 스캐너 구현·검증 기준

이 문서는 사용자 제공 기준을 스캐너 작업에 적용한 짧은 실행 기준이다. 코드와 화면이 다르면 화면을 기준으로 실패로 판단한다.

| 영역 | 적용 기준 |
|---|---|
| 사용자 화면 | 후보 목록이 아니라 **상세 카드에 실제 숫자**가 보이는 것을 완료 조건으로 한다. 카드에는 현재가, 추천 매수가 범위, 추천 매도가 1·2차, 손절가, 5·10·15·30분 방향만 우선 표시한다. |
| 가격 계산 | 가격은 완료봉·VWAP·EMA·스윙 지지·저항·거래량·거래대금·체결·호가·전략 조합을 사용해 계산한다. 구조 저항이 없을 때도 완료봉 모멘텀과 ATR 기반 계산값을 비워 두지 않는다. |
| 실시간 경로 | KIS 체결을 현재가의 단일 실시간 원천으로 사용한다. 캐시된 객체의 인터페이스가 바뀌면 캐시 키 버전과 스모크 테스트를 함께 갱신한다. |
| 실패 처리 | 후보 하나의 분석 실패가 전체 카드를 숨기면 안 된다. 오류는 분류하고, 안전한 시세·분봉 경로가 있으면 해당 경로로 카드를 계속 생성한다. |
| 테스트 | 내부 호출 횟수가 아니라 국내·미국 카드에서 실제 숫자와 실시간 가격 영역이 렌더링되는 공개 동작을 검사한다. 코드 변경 후 전체 회귀 테스트와 배포 화면 확인을 모두 수행한다. |
| 예측 검증 | 미국 장에서 예측 시각, 당시 현재가, 5·10·15·30분 예상값·방향·범위, 이후 실제값을 같은 시간 기준으로 저장해 방향·범위·목표 도달을 분리 검증한다. |
| 설명·문서 | 화면은 짧게 유지한다. 주석은 구현 설명이 아니라 캐시 무효화, 완료봉 제외 같은 이유와 불변조건만 남긴다. |

> 완료 선언 조건: 국내 또는 미국 화면에서 상세 카드가 보이고, 카드의 현재가·매수가·매도가·손절가·시간별 방향 숫자가 실제로 확인됐으며, 해당 변경의 테스트가 통과한 경우에만 완료로 판단한다.
