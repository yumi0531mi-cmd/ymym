# 혼합형 스캐너 통합 점검 기록

> **현재 운영 기준 업데이트 — 2026-08-18:** 아래 Yahoo 보조 시세 관련 내용은 과거 실험 기록이다. 주성엔지니어링의 KIS 기준가와 약 2,000원 차이가 확인돼 Yahoo 현재가·1분봉·의존성은 모두 제거했다. 현재 국내·미국 카드의 기준 현재가와 구조 계산은 KIS 원천만 사용한다.

## 목적

이 문서는 사용자가 제공한 **VWAP 5시간 지속형 스윙 반복단타 v4.0** 및 **초단타 VWAP·확률 기반 통합 설계 v3.3/v3.4**를 현재 스캐너와 대조한 기록이다. 목표는 상승 추세 눌림과 박스권 하단 회귀를 함께 다루되, **0.5~5.0% 반복 파동**, 유동성, 구조, 가짜 이탈 방어, 반복 피로도, 세션별 규칙을 하나의 최종 진입 판정으로 일관되게 적용하는 것이다.

## 현재 코드에 이미 반영된 핵심

| 요구 사항 | 현재 구현 위치 | 적용 상태 |
|---|---|---|
| 0.5~5.0% 반복 상승 Swing 최소 3회 | `scanner/persistence_engine.py`의 `extract_swings`, `final_buy_decision` | 적용됨 |
| 상승 추세형과 박스권형 분리 | `scanner/engine.py`의 `TREND_SWING`, `RANGE_SWING` | 적용됨 |
| VWAP·EMA·RVOL·거래대금·스프레드·손익비 | `scanner/engine.py`, `scanner/indicators.py` | 적용됨 |
| 5시간 지속성 점수와 반복 피로도 | `scanner/persistence_engine.py`의 `persistence_score`, `swing_statistics` | 적용됨 |
| 가짜 이탈·실제 붕괴·긴급 이탈 | `scanner/persistence_engine.py`의 `risk_state` | 적용됨 |

## 통합 원칙

두 보고서의 핵심은 별도 전략을 계속 추가하는 것이 아니라, 같은 신호를 여러 번 점수화해 과대평가하지 않는 것이다. 따라서 현재 구현처럼 **상승 추세형은 VWAP·EMA 지지 후 재상승**, **박스권형은 하단 지지 후 중앙선·상단 회복**으로 분기하되, 두 전략 모두 동일한 `FINAL_BUY` 관문을 통과해야 한다. 이 관문은 세션, 반복 Swing, 지속성, 진입 위치, 스프레드, 유동성, 비용 반영 손익비, 위험 상태, 쿨다운, Hard Kill, 그리고 표본이 충분할 때의 전체 경로 실측을 함께 확인한다.

5시간은 미래를 보장하는 숫자가 아니라, 90·180·300분 완료봉으로 신뢰도를 높이며 매분 재검증하는 지속성 평가로 다룬다. 장 초반에는 구조 표본 부족을 `EARLY_*` 상태로 보수적으로 표시하고, 300분 완료봉이 확보된 경우에만 `OBSERVED_300`으로 구분한다.

## 현재가 수신 분리

KIS 원시 WebSocket이 Streamlit Cloud 환경에서 연결되지 않을 때 카드 가격이 고정되는 문제를 보완하기 위해, Yahoo Finance WebSocket을 **보조 틱**으로 분리했다. KIS 체결이 있으면 KIS를 우선하고, KIS 틱이 없을 때만 Yahoo 보조 틱을 카드 현재가에 사용한다. KIS 1분봉이 31개 미만으로 구조를 계산할 수 없는 경우에만 Yahoo 1분봉을 별도 원천으로 사용해 해당 카드의 VWAP·반복파동·목표가·손절가를 계산한다. 하나의 카드 안에서는 KIS 틱과 Yahoo 1분봉을 섞어 계산하지 않는다.

Yahoo Finance는 거래소에 따라 실시간 또는 지연 데이터를 제공하므로, 화면은 항상 `KIS 체결`과 `Yahoo 보조 시세`를 출처별로 표시해야 한다. Yahoo의 문서는 WebSocket 구독·해지 기능을 제공하며, 많은 거래소에서 스트리밍 시세를 제공하지만 모든 시장의 실시간을 보장하지는 않는다고 명시한다. **100건 전체 경로 검증 기록은 KIS 체결이 있는 경우에만 저장**하므로 Yahoo 보조 데이터가 KIS 실측 성공률에 섞이지 않는다. [1] [2]

2026-08-18 장중 점검에서 `005930.KS`를 15초간 구독해 초 단위 timestamp가 다른 다수의 메시지와 가격 변화(269,750원 ↔ 269,500원)를 수신했다. 이 결과는 **보조 시세 스트림의 연속 갱신 가능성**을 보인 것이며, KIS 기준 체결가 일치나 목표가 검증을 대체하지 않는다.

같은 날 Streamlit Cloud 배포 화면에서 `Yahoo 보조 시세 수신 중 · 카드 현재가 1초 확인` 상태 문구가 표시되는 것을 확인했다. 다만 후보 카드 생성은 KIS 후보 조회가 끝난 뒤 시작되므로, 화면이 `시장 전체에서 가격 조건을 통과한 상승 후보를 자동으로 찾는 중…`에 오래 머무르는 경우에는 카드가 나타나기 전까지의 KIS 후보 조회 경로를 별도로 최적화해야 한다.

후보 카드가 처음 생성된 직후에는 해당 종목의 Yahoo 구독 메시지가 도착하기 전까지 `현재가 수신 대기`로 표시된다. 이는 이전 REST 가격을 실시간처럼 표시하지 않기 위한 안전 표시이며, 이후 1초 단위 fragment에서 실제 수신 틱만 현재가로 갱신한다. 이 동작은 카드가 보이는 상태에서 연속 가격·체결 시각을 추가로 확인해야 최종 검증으로 판정한다.

국내 후보 `950260` 카드에서는 KOSPI·KOSDAQ 이중 구독 보완 배포 후 `Yahoo 보조 시세` 출처와 14,310원 현재가가 표시되는 것을 확인했다. 카드의 `1초 확인` 시각은 매 fragment 실행마다 갱신된다. 다만 해당 종목의 마지막 Yahoo 체결 시각이 화면 확인 시각보다 오래된 경우에는 새 체결 자체가 없다는 뜻이므로, 화면 갱신 빈도와 개별 종목의 가격 변동 빈도를 같은 의미로 해석하지 않는다. 구조·목표가·손절가도 KIS 1분봉이 충분하면 KIS 기준을 우선하며, KIS 1분봉 부족 상태에서는 Yahoo 1분봉으로 계산 원천을 통일한다.

같은 카드의 다음 화면 확인에서는 현재가가 **14,310원에서 14,360원으로 변경**됐고, `Yahoo 보조 시세` 출처가 유지됐다. 따라서 무료 보조 스트림이 Streamlit Cloud 카드 현재가 영역까지 실제 연결돼 수신 가격을 반영하는 것을 확인했다.

Yahoo 1분봉 보완 배포 후 국내 후보 `396500 · TIGER 반도체TOP10` 카드에서 `박스 반복단타` 유형, 5·10·15·30분 상승 방향, 추천 매수가 구간(36,397.15~36,418.69원), 1차·2차 목표가(36,604.50원·36,863원), 차트 지지(36,346원), 손절가(36,019.58원)가 함께 계산되는 것을 확인했다. 이 카드의 현재가 출처는 `Yahoo 보조 시세`였고, KIS 1분봉 부족 시 Yahoo 1분봉을 같은 카드의 구조 계산 원천으로 쓴 결과다. 이 표시는 구조 계산 결과이며, KIS 체결 기반 전체 경로 실측 검증이 완료됐다는 뜻은 아니다.

후속 배포 화면 확인에서는 같은 카드의 현재가가 **36,360원에서 36,255원으로 다시 변경**됐고, 마지막 Yahoo 수신 시각도 변경됐다. 추천 매수가·1/2차 목표가·지지·손절가 및 5·10·15·30분 상승 방향은 같은 1분봉 구조가 유지되는 동안 일관되게 표시됐다.

## 남은 구현·검증

카드에는 5시간 지속성 등급·점수와 위험 상태를 짧게 표시한다. 현재가와 완료 1분봉은 KIS 기준만 사용하며, KIS WebSocket이 미수신이면 호출 제한을 지키는 KIS REST 스냅샷으로만 갱신한다.
