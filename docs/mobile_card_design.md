# 모바일 반복단타 후보 카드 설계

## 목적

휴대전화에서 여러 후보를 세로 카드로 빠르게 비교하면서도, 실제로 수신·계산된 값과 아직 확인되지 않은 값을 분명히 구분한다. 자동 주문은 제공하지 않으며, 모든 가격은 수동매매 판단용 참고값이다.

## 카드별 데이터 원칙

| 카드 영역 | 표시 항목 | 데이터 원천 | 미확인 시 처리 |
|---|---|---|---|
| 상단 | 종목코드, 종목명, 시장, 현재가, 등락률, 세션 | KIS 현재가 | 카드 생성 안 함 |
| 상태 | BUY/WAIT/BLOCK, 전략, 위험 상태, 점수 | 스캐너 엔진 | `대기` 또는 `확인 필요` |
| 경고 | 진입 보류 이유 최대 2개, 가짜 신호 경고 | 엔진 reasons·diagnostics | `특별 경고 없음` |
| 유동성 | 거래량, 거래대금, 상대거래량, 호가 스프레드 | KIS 현재가·호가, 지표 | `미확인` |
| 가격 계획 | 진입 기준가, 완료 5분봉 기반 1차/2차 목표, Soft/Hard Stop | 엔진 TradePlan | `조건 미확인` |
| 자세히 보기 | 지속성, 반복박스, 비용 반영 손익비, 세부 대기 이유 | 엔진 diagnostics | `미확인` |

## 호출 보호

전종목 후보 검색은 국내 2건·미국 6건의 순위 요청만 수행한다. 사용자가 명시적으로 선택한 후보 중 최대 3개만 카드 정밀분석하며, 종목당 현재가·호가·1분봉 조회는 최대 3건이다. 따라서 카드 일괄 분석은 최대 9건의 추가 요청이며, 1분 30건·5시간 1,100건의 앱 내부 예산을 계속 적용한다.

## 모바일 레이아웃

카드는 세로 1열을 기본으로 한다. 카드 안에서는 상단 종목·가격, 신호/위험 배지, 2열 유동성 지표, 3열 가격 계획을 차례로 배치한다. 화면 폭 700px 이하에서는 패딩·글자·열 간격을 줄이고, 사이드바는 처음에 접힌 상태로 시작한다. 긴 설명은 기본 카드에서 제거하고 `자세히 보기`에 둔다.

## 의도적으로 제외한 항목

공시·뉴스·기관/외국인 수급·실시간 호가잔량 불균형은 현재 스캐너의 수신 데이터 범위가 아니므로, 카드에 임의로 표시하지 않는다. 데이터가 추가될 때까지 추정 수치나 매수 우위 표현을 생성하지 않는다.
