# 국내·미국 혼합 단타 스캐너

한국투자증권(KIS) REST 데이터를 이용하는 **수동매매 보조용** Streamlit 앱입니다. 주문 API는 포함하지 않습니다.

## 핵심 원칙

- 국내 정규장, 미국 프리·정규·애프터 세션을 시간대별로 구분합니다.
- 현재가가 없으면 진입가·목표가·손절가를 만들지 않습니다.
- 목표와 손절은 완료된 실제 분봉의 스윙 저항·지지만 사용합니다.
- 60·15·5분 방향을 필터로, 1분봉과 호가를 실행 타점으로 사용합니다.
- 0.5~3.0% 박스와 상·하단 접촉이 확인될 때만 반복단타 가능으로 표시합니다.
- 예측은 5·10·15·30분 범위이며 네 구간이 모두 맞아야 `전체 경로 적중`입니다.
- 검증 실패·미검증 기록은 삭제하지 않습니다.

## Streamlit Secrets

```toml
KIS_APP_KEY = "발급받은 앱키"
KIS_APP_SECRET = "발급받은 앱시크릿"
KIS_BASE_URL = "https://openapi.koreainvestment.com:9443"
```

계좌번호는 필요하지 않습니다. 앱은 읽기 전용 시세 조회만 합니다.

## 실행

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

## 검증 정의

한 건은 `종목 + 신호 시각 + 코드 버전`입니다. 현재가 교차검증, 5·10·15·30분 전체 경로, 장세, 실제 저항 목표의 손절 전 도달을 모두 통과해야 완전 성공입니다. 실제 KIS 장중 데이터 검증 전에는 실전 검증 완료로 간주하지 않습니다.
