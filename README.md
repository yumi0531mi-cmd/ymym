# 국내·미국 혼합 단타 스캐너

한국투자증권(KIS) REST 데이터를 이용하는 **수동매매 판단 보조용** Streamlit 앱입니다. 주문 API는 포함하지 않으며, 어떤 신호도 수익을 보장하지 않습니다. 사용자가 직접 진입·청산을 결정하기 전에 시세, 호가, 지지·저항, 유동성, 세션, 비용 가정을 확인하도록 설계했습니다.

> 이 앱은 연구·분석 도구이며 개인 맞춤형 금융 자문이 아닙니다. 투자에는 손실 위험이 있습니다.

## 핵심 안전 원칙

| 영역 | 적용 내용 |
|---|---|
| 주문 | 읽기 전용 KIS 시세·호가·분봉 호출만 사용하며 주문 요청은 하지 않습니다. |
| 토큰 | Streamlit Community Cloud에서는 `KIS_ACCESS_TOKEN`을 Secrets에 직접 넣습니다. 앱의 토큰 자동 발급은 기본 차단됩니다. |
| 호출량 | 자동 새로고침은 기본 해제이며, 켜더라도 10·15·30·60초 중 선택합니다. 현재가·호가는 10초, 분봉은 60초 캐시합니다. |
| 매수 신호 | 완료된 분봉, 활성 세션, 다중 시간대 방향, VWAP/EMA, 상대거래량, 스프레드, 실제 진입 참고가 기준 순손익비, 최소점수를 모두 통과해야 합니다. |
| 반복박스 | 완료 5분봉에서 0.5~3.0% 범위와 상·하단 접촉을 확인하고, 현재가가 박스 안에 있을 때만 표시합니다. |
| 검증 | 신호 원본과 30분 사후 채점을 저장할 수 있습니다. 목표·손절이 같은 1분봉에서 동시에 닿으면 보수적으로 실패 처리합니다. |

## 주요 기능

앱은 국내 정규장과 미국 프리·정규·애프터 세션을 구분합니다. 유동성 시작목록은 전체 시장 스캔이 아니라 국내 14개, 미국 21개의 투명한 시작목록만 대상으로 합니다. 직접 종목 분석은 완료된 분봉을 사용하여 추세, 실제 진입 참고가, 확인된 저항·손절, 순손익비, 반복박스를 표시합니다.

`진입 고려`는 다음 조건이 모두 충족될 때만 표시됩니다.

| 필수 게이트 | 기본 기준 |
|---|---|
| 거래 세션 | 국내 정규장 또는 미국 프리·정규·애프터 세션 |
| 추세 | 5·15·60분 방향 합의가 상승 또는 박스 |
| 가격 | 완료 1분봉 VWAP와 EMA9 상회 |
| 유동성 | 상대거래량 1.0 이상, 시장·세션별 허용 스프레드 이하 |
| 구조 | 실제 매수 참고가보다 낮은 지지와 높은 저항이 모두 확인됨 |
| 순손익비 | 왕복비용 가정 반영 후 1.4 이상 |
| 점수 | 사이드바에서 정한 최소점수 이상(기본 85점) |

## Streamlit Secrets 설정

### 1. KIS 필수 Secrets

Streamlit Community Cloud의 **App settings → Secrets**에 아래 값을 넣습니다. 실제 값은 절대 GitHub에 올리지 마세요.

```toml
KIS_APP_KEY = "발급받은 앱키"
KIS_APP_SECRET = "발급받은 앱시크릿"
KIS_BASE_URL = "https://openapi.koreainvestment.com:9443"

# 매일 KIS에서 발급받은 접근 토큰을 입력합니다.
# Community Cloud에서는 자동 토큰 발급을 기본적으로 사용하지 않습니다.
KIS_ACCESS_TOKEN = "당일_접근_토큰"

# 선택: 정확한 만료 시각을 알고 있다면 ISO 8601 형식으로 입력합니다.
# KIS_ACCESS_TOKEN_EXPIRES_AT = "2026-08-18T07:00:00+09:00"

# 호출 보호 기본값입니다.
KIS_ALLOW_TOKEN_ISSUE = "false"
KIS_MIN_REQUEST_INTERVAL_SECONDS = "0.4"
KIS_MAX_RETRIES = "1"
```

`KIS_ACCESS_TOKEN`은 KIS의 현재 고객별 발급·유효 정책에 따라 관리해야 합니다. 토큰을 새로 발급한 뒤 Secrets에서 값을 교체하고 앱을 재부팅하세요. 앱 코드에서 `KIS_ALLOW_TOKEN_ISSUE=true`를 쓰는 것은 **로컬 개발 환경에만 한정**해야 하며, Community Cloud에서는 사용하지 마세요.

### 2. 선택: 검증·수동 매매 기록 영속 저장

Community Cloud는 로컬 파일 보존을 보장하지 않습니다. 검증 원본, 사후 채점, 수동 매매 기록을 재시작 뒤에도 보관하려면 Supabase 같은 외부 영속 저장소를 설정하세요.[1]

1. Supabase 프로젝트를 만듭니다.
2. SQL Editor에서 이 저장소의 `supabase_schema.sql`을 한 번 실행합니다.
3. Streamlit Secrets에 다음을 추가합니다.

```toml
SUPABASE_URL = "https://프로젝트-식별자.supabase.co"
SUPABASE_KEY = "서버-전용-키"
APP_ADMIN_PASSWORD = "관리자전용비밀번호"
```

`SUPABASE_KEY`는 서버에서만 사용하는 비밀값입니다. 브라우저 코드나 GitHub에 노출하지 마세요. `APP_ADMIN_PASSWORD`를 설정하면 검증 보고서와 수동 매매 기록 UI는 관리자만 볼 수 있습니다. 이 앱을 공개 배포하는 경우에는 별도 사용자 인증을 추가하기 전까지 관리자 비밀번호를 강력하게 설정하고 공유하지 마세요.

Supabase를 설정하지 않아도 종목 분석은 동작하지만, 기록은 `.scanner_data`의 임시 로컬 파일에만 남으며 Cloud 재시작 시 유실될 수 있습니다.

## 로컬 실행

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

로컬 개발에서만 자동 토큰 발급을 시험하려면 환경 변수 또는 로컬 `.streamlit/secrets.toml`에 `KIS_ALLOW_TOKEN_ISSUE="true"`를 명시해야 합니다. 이 옵션은 기본적으로 꺼져 있습니다.

## 검증 방법과 한계

한 건의 신호는 종목, 신호 시각, 코드 버전으로 구분됩니다. 5·10·15·30분 시나리오, 장세, 목표·손절 도달 순서 등을 보수적으로 채점합니다. 그러나 다음 한계가 있습니다.

| 한계 | 해석 |
|---|---|
| 검증 표본 | KIS 장중 데이터와 충분한 표본 수로 확인하기 전에는 실전 전략 검증 완료로 간주하지 않습니다. |
| 비용 | 기본 왕복비용은 국내 0.05%, 미국 0.10%이며, 실제 수수료·세금·스프레드·슬리피지와 다를 수 있습니다. |
| 시세 범위 | 최근 분봉만 받으므로 계산된 VWAP는 완전한 장중 누적 VWAP와 다를 수 있습니다. |
| 사후 채점 | 앱이 같은 종목을 30분 뒤 다시 확인할 때 채점됩니다. 지속 보관을 위해 영속 저장소를 권장합니다. |
| 신호 | 기술 조건을 통과한 정보일 뿐 매수 지시나 수익 보장이 아닙니다. |

## 테스트

```bash
pytest -q
```

테스트는 토큰 자동 발급 차단, KIS 응답 파싱, 데이터 부족 시 매매계획 은닉, 거래 불가 세션 차단, 반복박스 이탈 차단, 보수적 사후 채점, 영속 저장 미설정 시의 무동작 등을 다룹니다. 실제 KIS API 호출은 테스트에 포함하지 않습니다.
